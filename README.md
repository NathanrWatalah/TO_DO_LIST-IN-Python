Understanding The Project.

Meaning of “To-Do List”
A To-Do List is a list of tasks or jobs that a person needs to do.

 To-Do-List:
•	write tasks down
•	do them one by one
•	remove them when done

Real Life Example of a to-do list:
1. Wake up early
2. Study your lessons
3. Do homework
4. Go buy food in the market
5. cook
6. Eat
7. Take bath
8. Sleep

Project ALGORITHM (Step-by-step logic)
1. Start program
2.Create empty list call tasks
3. Repeat these steps:
•	Show menu options
•	Get user input
4. If user chooses:
•	Add → save task
•	View → display tasks
•	Remove → delete selected task
•	Exit → stop program
5. End program

PSEUDOCODE (Easy thinking steps)
START

Create an empty list called tasks

LOOP forever
    Show menu:
        1. Add task
        2. View tasks
        3. Remove task
        4. Exit

    Take user choice

    IF choice is 1
        Ask user for task
        Add task to tasks list

    ELSE IF choice is 2
        Show all tasks with numbers

    ELSE IF choice is 3
        Ask which task number to remove
        Remove that task from list

    ELSE IF choice is 4
        Stop the program

    ELSE
        Show error message

END LOOP
END
